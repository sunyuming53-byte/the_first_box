# ROS2 话题说明

rm_driver 是话题的核心发布/订阅节点。机械臂所有功能通过话题通信实现。

## 话题通信模式

每种操作对应一组 command/result 话题对:
- **Command**: 向 `/rm_driver/xxx_cmd` 发布指令
- **Result**: 订阅 `/rm_driver/xxx_result` 获取结果

## 控制器错误代码

| 序号 | 代码(Hex) | 内容 |
|------|-----------|------|
| 1 | 0x0000 | 系统正常 |
| 2 | 0x1001 | 关节通信异常 |
| 3 | 0x1002 | 目标角度超过限位 |
| 4 | 0x1003 | 该处不可达，为奇异点 |
| 5 | 0x1004 | 实时内核通信错误 |
| 6 | 0x1005 | 关节通信总线错误 |
| 7 | 0x1006 | 规划层内核错误 |
| 8 | 0x1007 | 关节超速 |
| 9 | 0x1008 | 末端接口板无法连接 |
| 10 | 0x1009 | 超速度限制 |
| 11 | 0x100A | 超加速度限制 |
| 12 | 0x100B | 关节抱闸未打开 |
| 13 | 0x100C | 拖动示教时超速 |
| 14 | 0x100D | 机械臂发生碰撞 |
| 15 | 0x100E | 无该工作坐标系 |
| 16 | 0x100F | 无该工具坐标系 |
| 17 | 0x1010 | 关节发生掉使能错误 |
| 18 | 0x1017 | 系统外受力数据校验失败 |

| 3 | 0x0002 | 过压 |
| 4 | 0x0004 | 欠压 |
